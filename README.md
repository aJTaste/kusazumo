# 草相撲 - PeerJS / Vercel版

元の草相撲をベースに、オンライン対戦をPeerJS + WebRTCへ置き換えたVercel向けプロジェクトです。

## 機能

### 遊び

- CPU対戦（連勝するほど強くなり、5連勝ごとにボス戦。連敗中は少し手加減）
- 部屋コード対戦 / ランダムマッチ / 友達招待URL（`?room=コード` を開くとそのまま同じ部屋に入れる）
- オンライン人数の概算表示（直近75秒以内にアクセスしたセッション数）
- 対戦中の草データ・準備状態・連打・勝敗をPeerJSのDataConnectionでP2P通信。ログイン不要

### 爽快感・やりこみ

- タップ演出：パーティクル・ダメージ数字・画面揺れ・コンボ（最大でダメージ1.5倍）・12%でクリティカル（2倍）・コンボ30でFEVER・連打で音階が上がる効果音・振動
- 決着はスローモーション＋紙吹雪（負けたら「あと◯%だった！」）
- 連勝カウンター、今日の初勝利ボーナス、レベル／称号、レベルで解放される草スキン（見た目だけで強さは変わらない）
- 「おまかせ」ボタン（どっしり／ギザギザ／バランス）で描かずに即スタート。前回の草は自動で復元
- シェアボタン（対応端末は共有シート、非対応はクリップボードにコピー）

### ガチモード（お手本そっくりに描く）

モード切替で「ガチ」を選ぶと、試合が始まるたびにお手本の草が出ます。制限時間15秒でお手本を見ながら一筆でまねて描き、**似ているほど強い草**になります（なぞれないよう、お手本は別のキャンバスに表示）。

- 再現度は形だけで判定（位置・大きさは無視、描く向きは逆でもOK、回転はNG）。太さはお手本に固定。描き終えると両者の再現度を見せてカウントダウン
- 再現度0〜100% → HPと引きに ×0.78〜×1.25（`GM` / `gachiMul`）。完璧でも最大差は約2.6倍の総合力なので、似ていなくても連打が桁違いに速ければ勝てる余地があり、完璧に描いても試合は一瞬では終わりません
- オンライン：お手本は両者の乱数（`ready` で送るnonce）をXORしたseedから作るので同じ形になる。草と再現度は描き終えたら `stem` メッセージで交換。ランダムマッチ・部屋コードともに**ガチ同士／ふつう同士で別の待機列・別の部屋**（APIの `mode`）。招待URLは `?room=コード&g=1`
- CPU戦もガチで遊べる（CPUは連勝が増えるほど上手にまねる）
- 時間内に描けなかった場合は再現度0の仮の草になります

### 試合時間とヒートアップ

- 試合時間は従来の約3倍（HPを3倍にし、鉄壁の回復量・軽減の効き方・粘りのコンボ上昇・会心などを調整。型どうしの三すくみは維持）
- 試合が8秒を過ぎると「ヒートアップ」：4秒ごとに両者のダメージが+100%（最大4倍）。HP型どうしの膠着で試合が終わらないのを防ぎます
- 数値は `index.html` の `TUNE`（`heal` / `spPw` / `floor` / `heat0` / `heatT` / `heatMax`）と `GM` に集約

進行状況（レベル・連勝・スキン・最後に描いた草）はこの端末の `localStorage`（キー `kusazumo.save.v2`）だけに保存され、サーバーには送られません。
OSの「視差効果を減らす」設定がオンの場合、揺れとフラッシュは弱まります。フラッシュは0.26秒に1回までに制限しています。

## 構成

- `index.html`: ゲーム本体（1ファイル。フォントはGoogle Fonts、通信はPeerJS 1.5.5をCDNから読み込み）（1ファイル。フォントはGoogle Fonts、通信はPeerJS 1.5.5をCDNから読み込み）
- `api/match.js`: 待ち合わせ、部屋コード照合、オンライン人数のAPI（`mode: 'g'` でガチ専用の待機列・部屋を使う）
- PeerJS Cloud: PeerJSのシグナリング
- Upstash Redis: 待ち合わせ情報とオンライン状態の一時保存

ゲーム中の連打イベントをVercel API経由で中継する構成ではありません。Vercel/Redisは相手を見つけるために使い、相手が見つかった後はPeerJSのDataConnectionで直接通信します。

## デプロイ手順

### 1. Upstash Redisを作る

1. UpstashのコンソールでRedisデータベースを作成します。
2. Freeプランを選びます（無料プランはクレジットカード登録不要です）。
3. データベースの詳細画面からRESTの`UPSTASH_REDIS_REST_URL`と、書き込み可能なStandard Tokenを取得します。
4. Tokenは公開しないでください。HTMLやGitHubへ貼り付けず、Vercelの環境変数だけに登録します。

このプロジェクトはRedisのLua `EVAL`を使って、同時に参加したユーザーのマッチングを原子的に処理します。

### 2. GitHubへアップロード

このフォルダ内のファイルを、GitHubリポジトリのルートへアップロードします。`index.html`と`api`フォルダが同じ階層にある状態にしてください。

### 3. Vercelへデプロイ

1. VercelでGitHubリポジトリをImportします。
2. Framework Presetは`Other`（または自動検出）にします。Build CommandとOutput Directoryは空欄のままで構いません。
3. Project Settings → Environment Variablesで、次の2つを登録します。
   - `UPSTASH_REDIS_REST_URL`
   - `UPSTASH_REDIS_REST_TOKEN`
4. ProductionだけでなくPreviewでもテストするなら、両方の環境に登録します。
5. Deployします。環境変数をあとから追加・変更した場合は再デプロイしてください。

### 4. 動作確認

1. デプロイしたURLを2つのブラウザ（または端末）で開きます。
2. 両方で草を描きます。
3. 部屋コード対戦なら、片方の表示コードをもう片方にも入力して対戦ボタンを押します。
4. ランダムマッチなら、両方で「ランダムマッチ」を押します。
5. 相手が接続されると「準備OK」が表示されます。両方が押すとカウントダウン後に対戦が始まります。

## ローカルで試す

Node.jsとVercel CLIを用意し、`.env.example`を参考に`.env.local`を作成してUpstashの値を設定します。

```bash
npx vercel dev
```

ブラウザで表示されたローカルURLを開きます。

## 注意点・制限

- PeerJS Cloudはシグナリングを担当します。実際のゲームデータはWebRTCで端末間を直接通信します。
- WebRTCはネットワーク環境によってP2P接続できないことがあります。PeerJS標準のSTUN/TURN（PeerJS公開の共用TURN）を使うようにしていますが、無保証の共用サーバーです。学校・企業のネットワークなどでは通信自体が遮断されることがあり、その場合は自前のTURNサーバーが必要です。
- オンライン人数はリアルタイムの厳密な同時接続数ではなく、直近75秒以内のハートビートを数えた概算です。ブラウザを閉じた直後などは最大75秒程度ずれることがあります。
- ガチモードの再現度・強さは各自のブラウザで計算して相手に送るため、改造すれば強い草を送れてしまいます（友達同士で遊ぶ前提）。
- Peer-to-peer方式なので、対戦結果をサーバーで検証する仕組みやチート対策はありません（受信するダメージ値には「申告タップ数×1タップの最大ダメージ」の上限だけ付けています）。レベルや連勝もブラウザ内の記録なので、書き換えれば改ざんできます。友人同士で遊ぶための試作向けです。
- PeerJS CloudおよびUpstash Freeの利用上限・提供状況は各サービス側の変更を受けます。
- オンラインAPIの環境変数が未設定でもCPU対戦は遊べます。オンライン対戦を押すと設定不足のエラーが表示されます。

## 外部ライブラリ

PeerJS 1.5.5をjsDelivr CDNから読み込んでいます。PeerJSの公式ドキュメントは https://peerjs.com/ です。

## オンライン対戦が動かないとき

画面のどこにエラーが出るかで原因が分かります。

| 表示                                                                   | 原因                                                                           | 対処                                                                        |
| ---------------------------------------------------------------------- | ------------------------------------------------------------------------------ | --------------------------------------------------------------------------- |
| 「対戦サーバーに接続できません」が出続け、オンラインのボタンが押せない | PeerJS Cloud(0.peerjs.com)に届いていない（サーバー停止・回線やブラウザで遮断） | 別の回線で試す。続くなら自前のPeerServerを使う                              |
| 「オンライン対戦に接続できません：Upstashの環境変数が未設定です」      | Vercelに環境変数がない                                                         | `UPSTASH_REDIS_REST_URL` と `UPSTASH_REDIS_REST_TOKEN` を登録して再デプロイ |
| 「…(HTTP 401)」「Vercelの保護設定でAPIが弾かれています」               | Deployment Protectionが有効                                                    | 本番ドメインのURLで開く、または保護設定を見直す                             |
| 「…(HTTP 404)」                                                        | `api/match.js` がデプロイされていない                                          | リポジトリのルートに `api/` があるか確認                                    |
| 「相手につながりませんでした」                                         | 相手が離脱済み、またはP2Pがつながらない回線                                    | 自動で2回まで探し直す。続くならモバイル回線で試す                           |
